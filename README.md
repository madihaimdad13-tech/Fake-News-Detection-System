# 📰 AI-Powered Fake News Detection System

An advanced Fake News Detection System built using Machine Learning, NLP, and Streamlit.  
This project detects whether news is REAL or FAKE using AI-based text analysis.

---

# 🚀 Features

- 🔍 Fake & Real News Detection
- 🎯 Confidence Score Analysis
- 📊 Interactive Charts & Dashboard
- 📂 TXT/PDF File Upload Support
- 🌍 Live News URL Detection
- 🤖 AI-Based Prediction System
- 🎨 Modern Streamlit UI

---

# 🧠 Technologies Used

- Python
- Machine Learning
- NLP (TF-IDF)
- Scikit-learn
- Streamlit
- Matplotlib
- BeautifulSoup
- PyPDF2
